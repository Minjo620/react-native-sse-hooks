# Security Policy

## Supported versions

Until the first public release, security fixes target the current `main` branch. After publication, the latest npm release is supported; older versions receive fixes only when the maintainer explicitly announces an extended support window.

## Reporting a vulnerability

Do not open a public Issue for a suspected vulnerability or include credentials, cookies, private endpoints, or personal data in a report.

Use GitHub's private vulnerability reporting page:

<https://github.com/Minjo620/react-native-sse-hooks/security/advisories/new>

Include the affected version or commit, impact, prerequisites, minimal reproduction, and any suggested mitigation. The maintainer will acknowledge the report through the private advisory and coordinate disclosure there.

No private contact email is published for this repository.
