# Code of Conduct

This project adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

All contributors and maintainers are expected to follow its pledge, standards, scope, enforcement responsibilities, and Community Impact Guidelines in repository Issues, pull requests, reviews, Discussions, and other spaces where they represent this project.

## Confidential enforcement reports

To report abusive, harassing, or otherwise unacceptable behavior without publishing a personal email address, use [GitHub private vulnerability reporting](https://github.com/Minjo620/react-native-sse-hooks/security/advisories/new) and prefix the report title with `[Conduct]`.

Reports will be reviewed promptly and fairly. The maintainer will protect the privacy and security of the reporter and apply the Contributor Covenant 2.1 enforcement guidelines.
